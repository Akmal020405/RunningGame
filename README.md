Proyek ini adalah game 3D sederhana yang dibuat menggunakan Unity 2021.3.45f1.
Game ini memiliki gameplay dasar berupa karakter yang berlari dalam lingkungan 3D, menghindari objek, dan mengumpulkan item.
✨ Fitur Utama
🌳 Lingkungan 3D Low Poly dengan objek seperti pohon, batu, semak, bunga, rumput, dan elemen alam lainnya.
🧍‍♂️ Player Controller sederhana untuk menggerakkan karakter.
⭐ Collectable Items seperti point atau objek khusus.
🎮 Gameplay ringan, cocok sebagai dasar pengembangan endless runner atau runner adventure.
🔧 Script inti seperti:
PlayerMovement
CollectPoint
MyInstants

📦 Struktur folder Unity yang rapi (Assets, Materials, Scenes, Prefabs, dsb).

🛠️ Teknologi & Tools
Unity 2021.3.45f1 (LTS)
C# scripting
Asset tambahan seperti:
AllSkyFree
SimpleNatureAssets
Blink Materials
