# 🌲 Simple Low Poly Runner Base Project

[![Unity](https://img.shields.io/badge/Unity-2021.3.45f1%20LTS-blue.svg)](https://unity.com/) 
[![C%23](https://img.shields.io/badge/Scripting-C%23-green.svg)]()
[![License](https://img.shields.io/badge/License-Free%20to%20Use-brightgreen.svg)]()

Proyek ini adalah dasar sederhana (*base project*) untuk game **runner 3D** atau **runner adventure** yang menggunakan aset **Low Poly**. Tujuan utamanya adalah menyediakan struktur ringan dan fungsional untuk **latihan** atau pengembangan awal game 3D di Unity, fokus pada *Player Movement* dan *Collect System* dasar.

## ✨ Fitur Utama

* **Lingkungan 3D Low Poly:** Dunia game yang dibuat dengan objek alam seperti **pohon, batu, semak, bunga, rumput**, dan elemen natural lainnya.
* **Kontrol Karakter Sederhana:** Sudah dilengkapi dengan **Player Controller** dasar (`PlayerMovement.cs`) yang siap digunakan.
* **Sistem Koleksi Item:** Implementasi script (`CollectPoint.cs`) untuk item koleksi sederhana (seperti poin atau objek khusus).
* **Gameplay Ringan:** Struktur yang ideal sebagai dasar pengembangan untuk game *Endless Runner* atau *Runner Adventure*.

## 🚀 Cara Memulai

1.  **Clone atau Unduh** repositori ini ke komputer Anda.
2.  **Buka Proyek** menggunakan **Unity Hub** dengan Unity Editor versi **2021.3.45f1 (LTS)** atau lebih baru.
3.  Buka Scene Utama: `Assets/Scenes/**SampleScene.unity**`.
4.  Tekan tombol **Play** (▶️) di Unity Editor.
